# 작은 공룡 달리기 🦖

크롬 공룡 게임에서 영감을 받은 HTML Canvas 미니 게임입니다. 외부 라이브러리나 이미지 없이 실행됩니다.

## 실행

`index.html`을 브라우저에서 열거나, 저장소 폴더에서 다음 명령을 실행하세요.

```sh
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`으로 접속합니다.

## 조작

- 시작 / 다시 시작 버튼으로 플레이
- 스페이스, 위쪽 방향키, 게임 화면 터치로 점프
- 선인장에 닿으면 게임 종료
- 시간이 지날수록 속도 증가, 최고 기록은 브라우저에 저장
- 다른 탭으로 이동하면 일시정지

## 파일

- `index.html`: 화면 및 스타일
- `game.js`: 게임 루프, 점프, 장애물, 충돌 및 점수

별도의 설치나 빌드 과정이 필요하지 않습니다.
